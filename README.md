# murlidharcreation.net

Serves the bare domain `murlidharcreation.net` with GitHub Pages:

- `app-ads.txt` authorises the AdMob account for Murlidhar Creation's apps (Mora). It must stay at the root of the domain listed as the Website on Google Play.
- `index.html` sends visitors on to the main site at www.murlidharcreation.net (Google Sites).
